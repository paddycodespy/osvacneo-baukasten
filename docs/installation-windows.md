# osVAC neo Baukasten unter Windows installieren

Voraussetzung: Windows 10 oder 11 (64 Bit).

Download: auf der [Release-Seite](https://github.com/paddycodespy/osvacneo-baukasten/releases/latest) unter **Assets** die Datei `osVAC-neo-Baukasten-…-Windows-Setup.exe`.

1. Die Datei `osVAC-neo-Baukasten-…-Windows-Setup.exe` starten. Sie installiert ohne Administratorrechte nur für dich.
2. Die Datei ist nicht signiert. Windows meldet deshalb „Der Computer wurde durch Windows geschützt“:
   auf **Weitere Informationen** klicken, dann **Trotzdem ausführen**.
3. Danach steht „osVAC neo Baukasten“ im Startmenü. Deinstallieren über *Einstellungen → Apps*.

Heruntergeladene Dateien (3MF, STL, STEP) landen im Ordner „Downloads“. Einen anderen Ordner wählst du im Schritt „Download“ unter „Speichern in“.

Fehlt auf sehr alten Windows-10-Installationen WebView2, lädt der Installer es selbst nach (Internet nötig).
